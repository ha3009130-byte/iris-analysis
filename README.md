\# Iris Dataset Analysis



\## Project Overview

This project analyzes the Iris dataset using Python and Pandas.



\## Setup

1\. Install Python and uv.

2\. Open the project folder.

3\. Create the virtual environment:

&#x20;  `uv venv`

4\. Install the required packages:

&#x20;  `uv sync`



\## Analysis

\- Displayed the first and last rows of the dataset.

\- Checked the dataset shape, columns, and data types.

\- Checked missing values and duplicate rows.

\- Counted the number of flowers in each species.

\- Calculated descriptive statistics and species averages.

\- Filtered and sorted the dataset.

\- Exported summary and filtered CSV files.

\- Created a bar chart showing average petal length by species.



\## Findings

\- The dataset contains 150 rows and 5 columns.

\- There are 3 species: setosa, versicolor, and virginica.

\- Each species has 50 rows.

\- Virginica has the highest average petal length, approximately 5.552.

\- The filtered dataset contains 61 rows where sepal length is greater than 6.
